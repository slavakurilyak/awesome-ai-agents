# Awesome AI Agents Curation Skill

This optional skill helps founders prepare evidence-backed submissions and helps maintainers review project issues and pull requests. It never approves projects or submits changes to GitHub.

## Install

Copy [`SKILL.md`](SKILL.md) into your agent's skills directory as `awesome-ai-agents-curation/SKILL.md`, then start a new agent session. For Codex, a personal skill can live at:

```text
~/.codex/skills/awesome-ai-agents-curation/SKILL.md
```

You can also use the skill directly from this repository by opening `SKILL.md` in an agent that supports repository skills.

## Workflow

- Founders gather project facts and links, check for duplicates, and prepare a ready-to-paste project issue.
- Maintainers inspect evidence and receive a concise recommendation with gaps and confidence; the human maintainer decides.
- The contribution rules live in [`CONTRIBUTING.md`](../../CONTRIBUTING.md).

For teams that want help building or deploying a custom AI agent, [schedule a discovery call with Slava](https://cal.com/slavakurilyak/discovery-call). Consulting is optional and unrelated to listing decisions.
